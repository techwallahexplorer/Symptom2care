## 🎨 **PLACEHOLDER QUALITY**

### **Characteristics:**
✅ **Descriptive** - Clear examples of what to enter
✅ **Helpful** - Guide users on format and content
✅ **Contextual** - Relevant to the field purpose
✅ **User-Friendly** - Easy to understand
✅ **Consistent** - Similar style across all fields

### **Examples of Good Placeholders:**

#### **Excellent:**
```html
<!-- Provides clear example -->
<input placeholder="Example: I have a headache and feeling tired for the past 2 days...">

<!-- Shows expected format -->
<input placeholder="your.email@example.com">

<!-- Gives helpful guidance -->
<textarea placeholder="List any medications you're currently taking..."></textarea>
```

#### **Standard:**
```html
<!-- Simple but clear -->
<input placeholder="John Doe">
<input placeholder="25">
<input placeholder="170">
```

## 📝 **QUICK REFERENCE**

### **If You Need to Add More Placeholders:**

```html
<!-- Text Input -->
<input type="text" placeholder="Enter your name">

<!-- Number Input -->
<input type="number" placeholder="25">

<!-- Email Input -->
<input type="email" placeholder="your.email@example.com">

<!-- Password Input -->
<input type="password" placeholder="At least 6 characters">

<!-- Textarea -->
<textarea placeholder="Describe in detail..."></textarea>

<!-- Search Input -->
<input type="search" placeholder="Search...">
```

### **Best Practices:**
1. Use examples that match expected format
2. Keep placeholders concise but descriptive
3. Use ellipsis (...) for longer content
4. Provide context-specific guidance
5. Match the tone of your application
